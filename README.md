# mcp-f1

F1 MCP — Formula 1 data via the Ergast API

Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

## Tools

| Tool | Description |
|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "f1": {
      "url": "https://gateway.pipeworx.io/f1/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use f1
```
